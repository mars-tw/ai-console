# v1.8.0 — 工作心智圖與可靠性修復

此版本新增獨立的工作心智圖，以工具、專案和既有工作紀錄提供可展開的檢視；未知或過期狀態會依來源區分。心智圖沿用既有龍角色素材，也提供減少動態與暫停選項。

本版補強本機服務啟動時的版本與程式身分確認、敏感 IPC 的來源檢查，以及互動終端仍在執行時的退出提示。產生發行候選包時使用隔離的來源快照與獨立輸出，不覆蓋既有安裝目錄。

舊派工紀錄缺少可核實的程序身分時，停止請求會回覆 `STOP_IDENTITY_UNKNOWN`，不會直接向 PID 送出停止訊號；等待中的舊工作仍可嘗試取消。取消登錄或工單更新未確認時會回覆 `CANCELLATION_RESULT_UNKNOWN`，需先查證原終端與紀錄，不應重送。

v1.7.0 的 ChatGPT「對話」＋ DevSpace MCP 草稿流程與獨立 OpenCode 入口維持不變。控制台不會自動貼上或送出 ChatGPT 指示；舊的新建工作、續作與重派 API 仍回覆 HTTP `409 USE_CHATGPT_CONVERSATION`，不會啟動 CLI。詳見[對話工作流程](../chatgpt-conversation-workflow.md)。
