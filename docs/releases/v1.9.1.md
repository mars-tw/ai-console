# v1.9.1 真實工作狀態與連線同步

獨立工作心智圖改用專用的 `/api/work-state` 唯讀來源，將既有工作登錄、終端結束證據、程序身分與工作階段 metadata 分開核對。工具、專案、龍角色與連線使用同一份快照，並顯示讀取時間、來源時間及涵蓋範圍。

舊紀錄缺少結束回執時會保留具體原因；程序不在、日誌非空或供應商回覆成功，都不再直接當成工作完成。停止紀錄與明確失敗證據仍會出現在工具詳情，與當前程序是否可核對分開呈現。程序 ID 重用及無法核對的身分不會顯示為執行中。

支援讀取本機 Claude 工作階段的狀態 metadata，核對執行檔與程序開始時間，保留來源回報的狀態和最後更新時間。這些工作階段與舊派工紀錄分開計數，也不推測它們對應哪個專案。近期回報忙碌或外部命令中的已核身階段可提供活動動效；過期自述、未知結果與 AI 供應商連線狀態另行標示。

進入可見心智圖時會讀取一次專用快照。「觀察目前工作」由使用者明確開啟，每 5 秒讀取、最多 2 分鐘；離開頁面、隱藏、離開可見範圍或來源過期時停止動效與觀察。讀取失敗會顯示舊資料及斷線狀態，恢復後以新的真實快照更新。

整個檢視不建立新派工、不啟動模型、不測試供應商，也不讀取對話正文或任務提示。專用端點不會修改原始紀錄。既有 ChatGPT、DevSpace、OpenCode 與舊派工執行邊界維持原有規則。

本版沿用 v1.9.0 的 MIT 動態設計與既有龍素材，沒有新增動畫引擎依賴。下載檔與 SHA256 校驗碼以本次 Release 為準。
