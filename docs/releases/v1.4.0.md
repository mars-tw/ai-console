# v1.4.0 — 接入 AI 與對話搜尋補強

- 新增「接入 AI／開始使用」精靈；沒有對話索引也能使用。
- 常見 AI 工具安裝檢查、官方說明與重新檢查；登入和派工能力不以安裝狀態冒充。
- 自訂本機或雲端 OpenAI 相容服務：取模型、儲存、測試回覆、開始文字問答。
- 手動金鑰僅留背景服務記憶體（關閉視窗不會清除）；支援環境變數名稱，變更服務網址須另建連線。
- 補上單份 JSONL、NDJSON、JSON 訊息陣列、SQLite 多對話的發現與索引。
- 手動搜尋不再沿用七天快取；新增擴大搜尋、資料夾選擇與未完成原因。
- 額外發現的工具對話以唯讀匯入，不擴大派工或來源修改權限。
- 保留手機遙控與既有四來源同步、技能匯入流程。

## 使用須知

Windows 版需要 Python 3.10+。手機遙控另需 Tailscale。
選擇雲端問答時，問題和該頁聊天紀錄會送到指定服務，可能計費。
自訂服務須提供 OpenAI 相容模型清單與文字聊天 API；LM Studio 使用內建安全入口。
搜尋有範圍與資源上限，不代表全磁碟完整掃描。

Windows 免安裝與原始碼 ZIP 均從同一 tag 乾淨產出；不含私人對話、連線設定、金鑰或手機配對資料。

## 驗證紀錄

- `npm run verify`：型別、零警告 lint、306 項前端與 503 項 Python 測試通過。
- 真實 CLI 隔離搜尋：4 種來源、5 份對話、9 則訊息匯出；來源檔雜湊不變、舊日期的唯讀匯入仍可見。
- 真實瀏覽器串接隔離 HTTP 服務：取得模型、儲存、回覆測試與聊天皆完成。這是流程驗證，並非所有外部供應商都已逐一實測。
- 獨立交叉驗證：手機端帶有效示範 token 仍無法存取 7 個新增私有設定／連線端點；唯讀匯入無法啟動、刪除或封存來源；Electron 資料夾選擇只接受主視窗主 frame。
