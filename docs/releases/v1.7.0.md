# v1.7.0 — 統一 ChatGPT 對話執行路徑與工作臺可靠性改善

AI Console 的編碼啟動與續作入口現在統一使用 **ChatGPT「對話」＋ DevSpace MCP**。控制台負責整理專案路徑、工作內容、模型偏好與有限近期背景；使用者仍須在 ChatGPT 選擇「對話」、加入 DevSpace、確認實際模型、貼上並自行送出。

控制台不會宣稱已代為貼上、送出或切換 ChatGPT 模型，也不再從公開工作臺入口建立、重派、接力或接續 CLI 工單。

## 統一的編碼執行與續作流程

以下入口都只準備 DevSpace 對話草稿，再帶到同一個 ChatGPT 對話入口：

- 首頁「交給 AI 執行」。
- 對話清單的「在 ChatGPT 對話續作」。
- 原派工主控台的新工作、重做與補充。
- 辦公室中控與角色工作按鈕。
- 手機遙控的新工作、重做與續作。
- 舊排程內容的人工接續。

續作最多帶入最近 6 則訊息，每則最多 300 字。這是給新 ChatGPT 對話的必要背景，不是恢復原 CLI session。唯讀匯入與 discovered 紀錄仍維持唯讀，只能作為有限背景。

「問 AI」、地端續聊與辦公室「說說看」仍是純文字問答，不會被當成讀寫專案或編碼執行路徑。OpenCode 也不會成為 ChatGPT 失敗時的自動替代方案。

## 舊執行 API 的明確邊界

下列舊 new-work／resume／retry／followup／batch／schedule 與 DevSpace 工作入口不再啟動工作，會回覆 HTTP `409`、`code: USE_CHATGPT_CONVERSATION`，並指向 DevSpace 分頁：

- `POST /api/launch`
- `POST /api/dispatch`
- `POST /api/dispatch/batch`
- `POST /api/dispatch/retry`
- `POST /api/dispatch/followup`
- `POST /api/schedule/save`
- `POST /api/schedule/run`
- `POST /api/devspace/run`
- `POST /api/devspace/continue`

`GET /api/dispatches` 現在只讀取舊紀錄，不會 flush pending、重派、啟動子行程或執行 auto-handoff。啟動伺服器時也不再啟動舊 Scheduler。

仍保留的舊工作能力只有：

- 查看歷史狀態與結果。
- 查看日誌。
- 查看 Git 差異。
- 停止仍在執行的既有舊工作。
- 取消尚未開始的既有舊工作。

停止與取消不會建立新工作。

## 六項工作臺 UX 改善

1. **頁籤往返保留草稿**：DevSpace 工作內容、專案資料夾與模型偏好在同一次控制台執行期間保留；不把 prompt 寫入永久儲存。「清除對話草稿」只清工作內容，專案與模型保留。
2. **準備狀態分開顯示**：載入中、未安裝、未設定、狀態不可讀、專案無效、內容空白、MCP 停止與 MCP 執行中都有不同原因與下一步；適用時直接提供啟動 MCP 或設定說明。
3. **安裝成功與 DevSpace 設定分離**：控制台安裝完成後，可選擇「稍後設定，先開啟控制台」；略過設定不會把既有認證當成失敗，也不會抹除已完成的安裝。
4. **DevSpace 資料夾選擇器**：桌面版可直接選擇資料夾；取消時保留原路徑，中文與空格路徑可用，瀏覽器仍可手動輸入，並持續遵守 `allowedRoots`。
5. **先複製、再開啟 ChatGPT**：新增主要操作「複製指示並開啟 ChatGPT」。只有剪貼簿成功後才會開啟網站；防止連點，失敗時保留草稿並提供手動替代方式。獨立複製與開啟按鈕仍保留。
6. **安裝進度如實呈現**：下載、驗證、安裝、建立捷徑等階段分開回報。尚未知道總數的檔案盤點顯示「已檢查 N 個檔案」，不偽造百分比；已知總數的複製與驗證才顯示百分比。

## OpenCode 獨立入口與真實 MCP 連線狀態

OpenCode 保留為使用者明確開啟的獨立工作臺入口，不是背景派工器或自動 fallback。

- 工作臺以實際 bridge／MCP 心跳判定連線，不把舊的 `connected` 進度紀錄永久視為已連線。
- 服務停止、bridge 消失或服務重啟時會回到可重試狀態並提供重新連接。
- 一般連線故障不再被誤標為 owner 授權失敗。
- DevSpace owner 授權、OpenAI 帳號登入與本機服務認證仍是分開的步驟。

本次沒有使用真人帳號重新實測 OpenCode OAuth，也沒有執行真實模型推論；「已安裝」、「已啟動」或心跳正常不代表帳號與模型已驗證可用。
