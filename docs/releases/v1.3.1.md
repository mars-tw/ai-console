# v1.3.1 — 對話、手機遙控與技能匯入修復

這是 v1.3.0 的修補版，保留手機配對方式與既有資料格式。

- 問 AI 的回答、草稿與模型選擇在切換分頁後保留；對話續聊的推理草稿另行收合，失敗重試不會污染後續上下文。
- 快速派工確實附上勾選的對話背景；辦公室使用即時工具清單，送出工作前明確確認。
- 手機配對會先驗證受保護的端點，錯誤會留在表單上；過期請求不會解除新配對。展開的日誌持續更新，失敗會重試。
- 手機應用頁面優先讀取新版，快取清理只影響本應用。
- 修正遙控靜態路徑可繞到私有資料的缺口，限制為手機頁面與有版本指紋的建置資源。
- 技能安裝比對預覽內容指紋；取消或切換來源會作廢舊回應，來源中途改變時要求重新預覽。格式檢查與實際 AI 相容性分開標示。
- 乾淨打包改用白名單暫存，並自動檢查私密檔案、本機路徑、配對碼、Windows 路徑衝突、必要檔案與版本。

Windows 免安裝包需要 Python 3.10+，或已安裝 Kimi Desktop 提供的 Python。手機遙控需先在電腦與手機安裝 Tailscale；桌面版開啟遙控後掃 QR 配對。

本次驗證包含三位獨立測試代理的桌面、手機視口與技能匯入實走，以及前後端回歸測試。瀏覽器操作使用示範資料，不會派出使用者的真實工作。

`npm run verify` 全過：292 個前端測試、431 個後端測試，共 723 項；TypeScript 與 ESLint 通過。手機頁在 320px、390px 視口沒有橫向溢出。
