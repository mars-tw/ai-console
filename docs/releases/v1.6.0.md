# v1.6.0 — ChatGPT 對話入口與 OpenCode 工作臺

DevSpace 分頁改為從 Chrome ChatGPT「對話」使用 MCP，新增獨立的 OpenCode 對話入口。模型直接透過 MCP 操作允許範圍內的專案，成果留在本機供原派工者檢查與接手。

## 下載

- [快速安裝包](https://github.com/mars-tw/ai-console/releases/download/v1.6.0/ai-console-quick-start-v1.6.0.zip)：完整解壓縮後執行 `快速安裝.cmd`。
- [Windows 64 位元免安裝版](https://github.com/mars-tw/ai-console/releases/download/v1.6.0/ai-console-win32-x64-v1.6.0.zip)：完整解壓縮後開啟 `AI控制台.exe`。
- [原始碼](https://github.com/mars-tw/ai-console/releases/download/v1.6.0/ai-console-source-v1.6.0.zip)：供開發者自行建置。
- [SHA256 校驗碼](https://github.com/mars-tw/ai-console/releases/download/v1.6.0/SHA256SUMS.txt)。

Windows 桌面包內含 Electron 與 Python；Node.js、Git Bash、DevSpace、OpenCode 與模型帳號需另外準備。[快速開始](../quick-start.md)及[完整安裝手冊](../install-and-run.md)已更新。

## 更新內容

- **DevSpace 對話入口**：選擇專案、準備並複製指示，開啟 Chrome ChatGPT；在「對話」加入 DevSpace 連接器後送出。此入口不呼叫 DevSpace agent 工作，不使用 ChatGPT「工作」或 Codex app-server。
- **模型選擇說明**：ChatGPT 實際模型須在其可見選單確認。面板偏好、提示文字或 Codex 模型識別碼不會遠端切換 ChatGPT 模型；指定模型無法使用時，不會自動改派其他模型。
- **OpenCode 工作臺**：支援 OpenCode 1.18.31，選擇專案與 GPT-5.6 SOL／GPT-6 ASTRA 預設模型後，開啟獨立對話視窗。登入使用 OpenCode 的正常 Connect 流程。
- **可隨包使用的 MCP bridge**：控制台內附連接官方 DevSpace 1.0.8 的程式，不需私人修改版。首次連線開啟正常 OAuth 授權頁，由使用者確認；工具綁定所選專案，OpenCode 的這個入口不開放背景子代理與 task 操作。
- **本機服務管理**：OpenCode 只綁定本機位址，每次啟動產生 Basic 認證；關閉視窗後可再次開啟，停止服務保留對話紀錄。切換專案或預設模型前需先停止服務。
- **首次安裝指引**：全新互動設定導向官方 `devspace init`，選擇 ChatGPT，再完成使用者自己的 MCP 入口與認證。已有設定與認證保留。

## 升級與使用界線

v1.5.1 使用者可下載 v1.6.0 快速安裝包重新安裝，再開啟桌面捷徑。舊版目錄保留；DevSpace 分頁改用對話流程，其他原有的搜尋、問答、技能與派工主控台功能保留各自入口。舊 DevSpace 工作 API 留作相容用途，新入口不會呼叫。

ChatGPT MCP 需有該帳號支援的連線方式與可到達的入口，本機健康檢查不能證明雲端連線正常。控制台不會自動建立公開網址、tunnel 或代為登入。詳見 [DevSpace 與 OpenCode 說明](../devspace-desktop.md)。

安裝成功、服務已啟動、模型出現在清單，都不代表模型帳號已驗證可用；實際對話結果才是依據。OpenCode 不會成為 ChatGPT 的自動替代路線。成果需讀回本機檔案並完成適當驗證，不能只憑聊天文字判定成功。

## 驗證

- TypeScript、ESLint、770 項前端測試與 673 項 Python 測試通過。
- 測試涵蓋官方設定入口、舊設定保留、安裝檔完整性、OAuth PKCE 與 callback 驗證、MCP 工具白名單、工作區及矛盾識別碼拒絕。
- ChatGPT 對話已實測透過 DevSpace 讀檔、執行檢查、寫入並讀回本機交接檔。OpenCode 新版 bridge 的首次 OAuth 仍由使用者在正常授權頁完成；本次不使用發布者的登入資料測試模型推論。
