# v1.9.2 Windows 正式啟動修復

修正本機沒有服務時，Windows 約兩秒才回報連線遭拒、卻超過原本兩秒自檢期限的問題。Python 與桌面程式的自檢期限調整為五秒，仍受整體啟動期限約束；真正逾時或身分不符時維持拒絕連接，不會接用或關閉不明服務。

Python 的本機健康檢查明確略過 proxy。服務程序提前退出時，桌面程式會立即辨識並顯示對應原因。啟動日誌只保留固定診斷代碼，不記錄未過濾的標準輸出或錯誤內容。

已存在且內容相同的遠端設定會略過重寫，保留原本的 token、位址與啟用狀態。舊排程仍不會因啟動而派出新工作。

v1.9.1 的唯讀工作心智圖與狀態查核保留。Windows 下載包仍包含固定版本 Python，不需要使用者重新安裝系統 Python。下載檔與 SHA256 校驗碼以本次 Release 為準。
