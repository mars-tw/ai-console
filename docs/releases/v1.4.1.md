# v1.4.1 — 新手設定、匯入與派工流程修復

## 一般使用者下載

Windows 使用者請下載 `ai-console-win32-x64-v1.4.1.zip`，完整解壓縮後開啟 `AI控制台.exe`。包內包含 Python 3.14.7，不必另外安裝或改動系統 Python。

`ai-console-source-v1.4.1.zip` 是開發用原始碼，不是可直接執行的 Windows 程式。

## 更新內容

- 沒有模型、工具尚未設定或讀不到狀態時，不再顯示可用並讓人誤派工。已安裝但登入未驗證的 CLI 另以中性提示顯示。
- 問答、舊對話接續與派工草稿在設定往返、失敗或取消後保留；同名不同對話不會互相吃掉草稿或誤送工作。
- **繼續工作對話框（新手）**：預設中文介面建立**新工單**，最多帶入最近 6 則、每則 300 字的對話背景；**不宣稱**恢復原 AI 的完整舊 session。原工具預選且不會被自動改換；僅 headless 派工。英文原工具終端改為明確的進階選項，附雙語安全提示；關閉對話框時焦點會還原到觸發按鈕。
- 首頁入口持續可見，回首頁後重新整理不會再跳回舊對話；窄螢幕側欄會正確收起。
- 接入 AI 改為明確的初次使用步驟；DeepSeek、OpenRouter、智譜通用 API 提供預設網址與官方入口。智譜 `/v4` 不再被接錯；只有明確缺少模型清單的服務才開放手填，登入錯誤仍會攔下。
- 未使用的對話來源可以略過；真實權限、格式及未完成搜尋問題仍會提示，唯讀匯入也計入成功數量。
- 兩個純文字入門技能可直接預覽並安裝，沿用內容指紋與不覆寫檢查；安裝後附原 AI 的使用與測試步驟，不把檔案安裝成功冒充 AI 執行成功。
- 本機模型明示只產生文字回答、不改檔；本機工作不會被自動轉交雲端或可改檔的 CLI。
- 修正地端安全檢查的實際 Windows / CPU runtime 格式判讀；檢查程式崩潰、回報矛盾或未知硬體狀態均不放行。
- 更新首頁、接入、同步、技能、派工、繼續工作與手機展示圖，均使用示範資料。

## 使用界線

AI 工具、模型及雲端帳號不包含在下載包內。控制台不會替你註冊、購買額度或自動下載大型模型；雲端問答會將問題與目前聊天內容送到你選擇的服務，可能計費。

本機入口使用 LM Studio 與 CPU llama.cpp (Windows) 2.24.0，保留既有機器安全檢查的優先權，不卸載或接管其他工作的模型。手機遙控另需 Tailscale；對話、技能與設定端點仍不對手機遙控開放。
