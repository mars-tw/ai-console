# v1.9.0 獨立龍心智圖

工作心智圖以工作中樞連接 AI 工具與專案，逐一繪出節點分支。選取節點可查看詳情與對應分支，搜尋可縮小檢視範圍，並提供縮放及適合視窗的操作。

龍角色沿用專案既有素材。任務、龍與分支線條使用同一份任務快照：只有確認執行中的任務顯示流動連線，來源工具的「活躍」不等於正在執行任務。分支表示節點與中樞的關係，不表示供應商已連線，也不推測工具已被指派給特定專案。

任務資料仍需按「更新任務資料」才讀取一次。進入心智圖不會建立新工作或在背景輪詢；資料未讀取、讀取失敗或取消結果不明時，介面會保留相應狀態。暫停、減少動態、頁面隱藏或離開可見範圍時停止動效。

本次動態設計參考 [LottieFiles motion design skill](https://github.com/LottieFiles/motion-design-skill/tree/f9a8a041b85185ee4881b3471d3415e939aac772) 的 MIT 技能，使用既有 React 與瀏覽器 CSS、SVG，沒有新增動畫引擎依賴。技能原文的授權為 [MIT](https://github.com/LottieFiles/motion-design-skill/blob/f9a8a041b85185ee4881b3471d3415e939aac772/LICENSE)；龍素材與專案內保留的第三方授權分別依 README 與 `licenses-ai-office-MIT.txt`。

ChatGPT 對話、DevSpace 草稿與 OpenCode 的既有入口保留，舊派工建立及續作 API 的安全邊界沿用 v1.8.0。下載檔與 SHA256 校驗碼以本次 Release 為準。
